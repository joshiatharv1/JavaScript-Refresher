1. CORS Error: An error faced when two different services running on two different URL/Origins on different ports need to communicate. 
   Solution: 
   On Backend Side: 
   Install the CORS Package and app.use(cors())
   We have the ability to whitelist the URL from from there we want to recieve or reject data
   If no cors that means anyone from any where can send multiple request to your endpoint to send data. 
   On Frontend Side: 



2. You should use Proxy to standardize the URL that you want to send or recive data from. For instance the www.atharvWeb.com/api/jokes might later 
   become the www.atharvnewWebsite.com/api/jokes. 
   To break this manual effort use proxies. 
   If you made an simple React Application without any bundlers or toolkits like Vite
   you can simply add an Property called the "proxy":"localhost:6000/api/jokes //"
   
   Otherwie look at the vite.config.js for this
   export default defineConfig() method
