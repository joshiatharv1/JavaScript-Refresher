1. Object Literal: An object literal is the easiest way to create an object in JavaScript. You define key–value pairs inside {}.
It is used when you need just one object and don’t need a reusable blueprint.

Example
const user = {
  name: "Atharv",
  age: 22,
  greet: function() {
    console.log("Hello " + this.name);
  }
};

console.log(user.name);
user.greet();
Output
Atharv
Hello Atharv
Key idea
Object Literal = Direct object creation

Structure:

Object
 ├── properties
 └── methods
2. Constructor Functions: When you need many objects with the same structure, writing object literals repeatedly is inefficient.
A constructor function acts like a blueprint for objects.

You use the new keyword to create objects.

Example
function User(name, age) {
  this.name = name;
  this.age = age;
}

const user1 = new User("Atharv", 22);
const user2 = new User("Rahul", 25);

console.log(user1.name);
console.log(user2.name);
Output
Atharv
Rahul
What new does internally

When you write:

new User("Atharv",22)

JavaScript does:

1️⃣ Creates empty object
2️⃣ Links it to prototype
3️⃣ this points to that object
4️⃣ Returns the object

Visualization
User Constructor
      │
      ▼
user1 object
user2 object
3️⃣ Prototype
Theory

JavaScript uses prototype-based inheritance.

Every function automatically gets a prototype object.

This allows sharing methods across objects instead of duplicating them.

Without prototype:

Every object copies the same method → waste memory

With prototype:

All objects share the same method
Example
function User(name) {
  this.name = name;
}

User.prototype.sayHello = function() {
  console.log("Hello " + this.name);
};

const user1 = new User("Atharv");
const user2 = new User("Rahul");

user1.sayHello();
user2.sayHello();
Output
Hello Atharv
Hello Rahul


Prototype Chain
user1
  │
  ▼
User.prototype
  │
  ▼
Object.prototype
  │
  ▼
null

If JS doesn't find a method in the object, it looks up the prototype chain.

4️⃣ Classes (Modern Syntax):Classes were introduced in ES6 (2015). They are syntactic sugar over prototype-based inheritance.
Class = Cleaner syntax for prototype
Example
class User {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  greet() {
    console.log("Hello " + this.name);
  }
}

const user1 = new User("Atharv", 22);
user1.greet();
Output
Hello Atharv
Under the hood

This class:

class User {}

is actually converted to:

function User() {}
User.prototype.method = function(){}
5️⃣ Instances (new and this)
Theory

An instance is an object created from a class or constructor.

Example:

class → blueprint
instance → actual object
Example
class Car {
  constructor(brand) {
    this.brand = brand;
  }

  drive() {
    console.log(this.brand + " is driving");
  }
}

const car1 = new Car("Toyota");
const car2 = new Car("Tesla");

car1.drive();
car2.drive();
Output
Toyota is driving
Tesla is driving
this keyword

this refers to the current object instance.

Example:

console.log(this.brand);

Means:

Access the brand of the current object
