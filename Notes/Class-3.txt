-- Copy Types in Java
    Reference Copy – No new object created. Both variables point to the same object in Heap.
    Car a = new Car(); Car b = a; → a and b are the same object
    
    Shallow Copy – New object IS created, but inner objects (like Engine) are still shared.
    Change b.engine.power → affects a.engine.power too.
    Car myNewCar = new Car();
    Car myNewOtherCar = myNewCar.clone(); // NEW object, but...


    Deep Copy – New object created AND all inner objects are also fully copied. Nothing is shared.
    Change anything in b → a is completely unaffected

    Reference Copy → Same object, two names
    Shallow Copy → New object, but shared insides
    Deep Copy → Fully independent clone

-- IMPORTTANT INTERVIEW QUESTIONS: 
1. Whats higher order funcitons?
Functions that operate on other functions, either by taking them as arguments or by returning them, are called higher-order functions.
Higher-order functions are a result of functions being first-class citizens in javascript.

Examples of higher-order functions:
function higherOrder(fn) {
  fn();
}
higherOrder(function() { console.log("Hello world") });  
function higherOrder2() {
  return function() {
    return "Do something";
  }
}      
var x = higherOrder2();
x()   // Returns "Do something"

2. Use Strict Mode does what ?
Duplicate arguments are not allowed by developers.
In strict mode, you won't be able to use the JavaScript keyword as a parameter or function name.
The 'use strict' keyword is used to define strict mode at the start of the script. Strict mode is supported by all browsers.
Engineers will not be allowed to create global variables in 'Strict Mode.

3. This keyword
The “this” keyword refers to the object that the function is a property of.
Since the function is invoked in the global context, the function is a property of the global object.
Therefore, the output of the above code will be the global object. Since we ran the above code inside the browser, the global object is the window object.
