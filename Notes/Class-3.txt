-- Copy Types in Java
    Reference Copy – No new object created. Both variables point to the same object in Heap.
    Car a = new Car(); Car b = a; → a and b are the same object
    
    Shallow Copy – New object IS created, but inner objects (like Engine) are still shared.
    Change b.engine.power → affects a.engine.power too.
    Car myNewCar = new Car();
    Car myNewOtherCar = myNewCar.clone(); // NEW object, but...


    Deep Copy – New object created AND all inner objects are also fully copied. Nothing is shared.
    Change anything in b → a is completely unaffected

    Reference Copy → Same object, two names
    Shallow Copy → New object, but shared insides
    Deep Copy → Fully independent clone
