12. What is Interface and Type in Ttypescript?
    Interface → "What should this object look like?" (and it can evolve)
    Type → "What name do I give this thing?" (and it's set in stone)
    Look at the InterfaceAndType.ts file.
    Both Interface and type explain the SHAPE OF DATA
    let student={
        name: "Atharv",
        rollNo: 25
    }
    interface student{
        name:string,
        rollNo: number
    }
    type student={
        name: string, 
        rollno: number
    }
    Important Concept : Intersection used in types where as extends in Interface only
    Use interface when:
    You are describing objects
    You are working with classes
    You want declaration merging
    You want cleaner object modeling
    
    Use type when:
    You need unions
    You need primitives
    You need tuples
    You need complex combinations
    You’re building advanced type logic
    
    In modern TypeScript:
    Use type for most things
    Use interface for object shapes that might be extended

Some teams even use only type.
